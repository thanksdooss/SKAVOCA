## 🏛️ 시스템 아키텍처 (배포 기준)

```
[교육생 브라우저] ── Vue 3 SPA (Vercel)
        │   · 발음 듣기: 브라우저 내장 음성 합성(Web Speech API)
        │
        ▼  REST API (JWT)
[Spring Boot 3.4 · Java 21] ── Docker on Render
        ├─ 1. 레벤슈타인 거리 기반 오타 허용 채점
        ├─ 2. SM-2 간격 반복 (응답 시간·힌트 사용으로 품질 q 자동 산출)
        ├─ 3. 오답 피드백: 등록된 혼동 오답은 DB 조회, 미등록 오답은 한국어 템플릿으로 생성
        ├─ 4. 게이미피케이션: XP 지급, 티어 승급, 주간 리그 갱신
        └─ 5. 강사용 통계·어휘 관리 (역할 기반 접근 제어)
        │
        ▼
[PostgreSQL (Neon, SSL)]
   - users, words, user_progress, review_logs
   - confusing_distractors, weekly_league
```

> 운영 서버 슬립 방지를 위해 GitHub Actions가 주기적으로 헬스 체크를 호출합니다.

## 💎 핵심 기능

1. **SM-2 간격 반복 자동화**
   - 정답 입력 후 난이도 선택 팝업 없이, 응답 시간(T)과 힌트 사용(H)으로 품질(q)을 자동 산출해 다음 복습일을 서버에서 계산합니다.
2. **레벤슈타인 거리 기반 오타 허용 & 단어 블록 UI**
   - `kubctl` 같은 1글자 오타에는 재입력 기회를 주고, 모바일에서는 탭으로 조립하는 단어 블록 UI를 제공합니다.
3. **DB 기반 오답 피드백**
   - 자주 틀리는 혼동 오답(`tar` ↔ `zip` 등)은 DB에 등록된 비교 해설을 보여 주고, 등록되지 않은 오답은 한국어 템플릿으로 피드백을 만듭니다. (LLM 호출 없음)
4. **브라우저 음성 합성으로 발음 듣기**
   - 별도 유료 TTS API 없이 Web Speech API로 용어 발음을 재생합니다.
5. **개발자 성장 티어 & 주간 리그**
   - `코딩 노비` → `CTO`로 성장하는 티어와 동기 간 주간 리그로 매일 학습을 이어 가게 합니다.

## 🔐 보안

- Spring Security + JWT (access 30분 / refresh 7일), BCrypt 비밀번호, 로그인 실패 잠금
- 운영 환경의 `JWT_SECRET`은 Render가 생성한 환경변수만 사용합니다 (코드에 기본값 없음)

## 📝 설계 문서와 배포 구현의 차이

위 설계 문서 4종은 미니 프로젝트 제출 시점(2026.08)의 설계안이며, 원본 그대로 보존합니다. 현재 배포 버전은 다음 부분이 설계와 다릅니다.

| 항목 | 설계 문서 | 배포 구현 |
|---|---|---|
| 데이터베이스 | MariaDB | PostgreSQL (Neon) |
| 발음 듣기 | Google Cloud TTS → S3/CloudFront 캐싱 | 브라우저 내장 음성 합성 (Web Speech API) |
| 미등록 오답 피드백 | LLM 생성 후 DB 캐싱 | 한국어 템플릿 생성 (LLM 호출 없음) |
