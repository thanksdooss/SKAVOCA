## 💎 5대 핵심 엔지니어링 혁신 요약

1. **암묵적 평가(Implicit Assessment) 기반 SM-2 자동화**:
   - 정답 입력 후 불필요한 난이도 선택 팝업을 제거하고, 응답 시간($T$)과 힌트($H$)로 Quality($q$)를 자동 산출하여 말해보카 수준의 경쾌한 몰입감 제공.
2. **레벤슈타인 거리(Levenshtein Distance) 퍼지 매칭 & 단어 블록 UI**:
   - `kubctl`과 같은 1글자 단순 오타에 재입력 기회를 부여하고, 모바일 가상 키보드 피로를 완치하는 탭 기반 단어 블록 조립 UI 탑재.
3. **DB 캐시 기반 지능형 오답 피드백 & Cache-Aside**:
   - 사전에 등록되지 않은 오답(`tar`, `zip`) 입력 시 LLM이 비전공자 맞춤 1문장 비교 해설을 생성하고 DB에 즉시 캐싱하여 0ms/0원 자가 증식 아키텍처 완성.
4. **S3 / CloudFront CDN 기반 오디오 사전 렌더링**:
   - Google TTS를 단어 등록 시점에 단 1회만 호출하여 S3에 영구 캐싱함으로써, 학습 중 매번 발생하는 유료 API 호출 비용을 99.9% 절감하고 0.1초 초저지연 재생 달성.
5. **개발자 RPG 성장 티어 & SKALA 4기 주간 랭킹 리그전**:
   - `코딩 노비` $\to$ `CTO`로 성장하는 티어 시스템과 동기 간 주간 리그전으로 매일 학습을 지속시키는 강력한 상업적 도파민 락인 루프 구축.
